# Minecraft Dragon Mod 🐉

**A majestic Fabric mod that adds dragons to Minecraft!**

Created by the kind dragon with a saddle (and his rider).

## Features (planned)
- Custom dragon entities (rideable!)
- Dragon eggs that hatch
- Dragon scales, armor and weapons
- Fire breath attacks
- New biomes or structures with dragons

## Requirements
- Minecraft 1.21+
- Fabric Loader
- Fabric API

## Installation
1. Install Fabric Loader and Fabric API
2. Download the mod jar from Releases
3. Place into your `.minecraft/mods` folder

## Development
This is a starting template. To fully develop:
- Use the Fabric example mod structure
- Add entity models, textures, AI, etc.

Feel free to contribute! Open issues or pull requests.
